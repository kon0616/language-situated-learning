# Language Web / 语言网

本地运行的多语言学习原型。可以从 Inbox 保存真实输入，在材料库回看原文和提取片段，也能从 Today、Context、Domain、Explore 和再次遇见几个入口查看表达。左侧「语言空间」可按学习语言切换，既有日语数据会自动保留为日语。

## 运行

需要 Node.js 22.18+ 与 npm：

```sh
npm install
npm run dev
```

默认地址为 `http://127.0.0.1:5173/`。运行 `npm test`、`npm run typecheck`、`npm run build` 验证。

Netlify 部署使用根目录的 `netlify.toml` 执行 `npm run build`，发布 `dist`，并部署 `netlify/functions/deepseek.mts` 提供线上分析与注音。线上 API Key 和模型只保存在当前浏览器的网站存储中；每次请求通过本站 Netlify Function 转发到 DeepSeek，密钥不会写入 GitHub 或作为全站共享的服务端配置。共用设备上请在 AI 配置中删除密钥。线上长材料按较小片段逐次分析，以适应函数的执行时限。`localhost` 与 Netlify 域名的浏览器存储互不共享，已有本地材料和 API Key 不会自动出现在部署站点。

## DeepSeek 材料分析

在左侧 **AI 配置** 中填写 DeepSeek API Key、模型，并编辑「材料分析与归类提示词」，点击「保存配置」。回到 Inbox，粘贴材料，选择「自动识别」或手动指定本次学习语言，再选择释义语言，点击「分析材料并提取语言」。服务会识别材料中的语言，按本次学习语言提取表达，给出材料概览和 Context、Domain、Function 建议。混合材料的检测语言会一并显示；手动指定的学习语言与实际材料语言分开记录。逐条检查、编辑或取消勾选后再保存到材料库。没有配置 Key 时，Inbox 仍可用本地日语 Mock 示例提取。

默认提示词会逐段寻找各语言中可复用的说法、有趣搭配和常见搭配，不设“只留 10 个”的名额；搭配可以作为独立表达保存。服务会按学习语言追加补充规则；目前日语、英语、中文和法语有专门规则，其余语言使用通用规则。较长材料按约 2000 字符分段，会发起多次 DeepSeek 请求，数量取决于材料长度。多个片段里重复的表达会合并，原文与材料卡片仍保持完整。此前保存在浏览器中的旧版默认提示词会自动换成新版；自行编写的提示词继续保留，也可在 AI 配置中点击「恢复默认」。

如果某一段的模型输出被截断，服务会自动把该段再拆小并重试，已经完成的段落不会在本次分析中重复请求。重试也可能增加 API 请求次数；如果极短片段仍被截断，界面会提示检查自定义提示词。

默认接口为 `https://api.deepseek.com/chat/completions`，模型为 `deepseek-flash`。本地开发时，API Key 与模型保存在本机项目的 `.language-web/api.json` 中，不写入浏览器存储，重启服务后自动加载。此文件包含明文密钥，已加入 Git 忽略并禁止通过开发服务器访问；不要分享该目录。也可复制 `.env.example` 为 `.env` 并填写 `DEEPSEEK_API_KEY`。模型也可通过 `DEEPSEEK_MODEL` 设置。线上版则把各自的 Key 保存在各自浏览器，并在主动分析或注音时发往本站函数和 DeepSeek。提示词也只保存在当前浏览器，原始材料只会在主动点击分析时发送。浏览器本地数据没有云同步或备份。

## 材料与表达

- Inbox 保存一份输入时创建一张材料卡片。材料保留标题、类型、日期、学习语言、检测到的材料语言和当时输入的原文。
- `SourceOccurrence` 记录“某个表达在某份材料中出现”的关系和原句。同一个表达再次从新材料提取时会复用表达节点，并为新材料添加出现记录。
- 材料详情显示原文、提取时保存的片段和可点击的表达。初次加载只展示少量卡片和片段，更多内容按需展开。
- 打开材料后可点击「删除材料」。确认后会删除原文、片段和出现记录；只属于这份材料的表达会删除，共享表达会改指向其他仍存在的材料。
- Node Detail 显示这个表达出现过的材料；再次遇见的原始输入回声也从材料出现记录中选取。
- 「再次遇见」从完整原文寻找含已收藏表达的句子；紧邻的句子可以作为上下文，但不会单独占一个轮换位置。可选择「我的全部材料」、单份材料或「精选场景」，再逐段轮换。点击表达会在当前页右侧打开详情，只有主动点击材料来源才会进入材料库。场景页也会显示相关的原文片段。「全部语言」视图中的表达卡片会标明语言。

旧 v2 浏览器数据会根据表达原有的 `sourceId` 和 `sourceContext` 补出出现记录，并补上日语语言标记；v1 数据先执行原有分类迁移，再补出记录。原有表达、状态和来源仍保留。存储键仍是 `language-web.v2`。不同学习语言的同形表达会保留为独立节点。

材料原文、表达和出现记录写在当前浏览器对该本地站点的 `localStorage` 中。刷新页面、关闭浏览器或重启本地服务后通常仍在；清除网站数据、改用其他浏览器或浏览器配置文件、隐私模式结束、存储空间不足时则可能丢失。目前没有云同步或自动备份，因此不能视为永久保存。保存失败时应用会显示警告。

日语提取的表达会尝试附上平假名和汉字注音；模型给出的分段注音只有在与原表达逐字对齐时才会显示。旧日语表达可在详情右侧点击「生成汉字注音」，也可手动填写读音。材料原文中已收藏且有分段注音的表达会显示注音；材料片段每页显示 15 条。AI 配置中提供「一键补全现有表达注音」，只处理日语空间中尚无读音的含汉字表达，并逐条保存；可以停止，再次点击会跳过已完成项。其他语言的读音可手动填写。自动生成和查询使用已配置的 DeepSeek API，并可能产生请求费用；手动填写不需要 API。

## 当前原型范围

未配置 DeepSeek 时，输入提取仅支持本地日语 Mock；再次遇见中的日语场景仍使用精选示例，其他语言从已保存材料回看真实原句，不会生成新的外语对话。材料详情中的片段来自保存时的原始上下文，目前没有完整文件上传、音视频时间戳或云同步。材料分析提示词在 `src/prompts/materialAnalysis.ts`，DeepSeek 服务入口在 `src/server/deepseek.ts`，Mock 提取在 `src/services/extractor.ts`，片段组织逻辑在 `src/services/fragmentGenerator.ts`。数据结构在 `src/types/language.ts`，保存与迁移分别在 `src/services/saveExtraction.ts` 和 `src/services/storage.ts`。
